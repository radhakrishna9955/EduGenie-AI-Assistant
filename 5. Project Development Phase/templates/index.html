Why EduGenie? Hybrid AI Architecture

Modern educational assistants often struggle with latency or privacy bottlenecks. EduGenie addresses this with a Hybrid Cloud + Edge AI infrastructure.

High-reasoning synthesis tasks leverage Google's cutting-edge Gemini 2.5 Flash API in the cloud, while sensitive concept explanations and local processing run on Hugging Face's lightweight LaMini-Flan-T5 model right on your machine.

⚡ Next-Gen System Stack
  • ☁️

    Cloud AI (Google Gemini 2.5 Flash)

    Powers ultra-fast contextual Q&A, multi-stage summarization, structured JSON quiz compilation, and progressive roadmaps.

  • 💻

    Local Edge AI (LaMini-Flan-T5-783M)

    Executes fast, resource-friendly conceptual explanations locally with zero external API dependencies.

  • 🛡️

    FastAPI + SQLAlchemy SQLite Database

    Persistent multi-user study sessions, secure SHA-256 auth, cookie sessions, and instant full-text query history retention.
